#Task API

A simple REST API built with Python and FastAPI.

This project implements CRUD operations for tasks using an in-memory list.

#Features

- Health check endpoint
- Get all tasks
- Get a single task
- Create a task
- Update a task
- Delete a task
- Input validation
- Automatic task IDs
- Interactive Swagger API documentation

#Requirements

- Python 3
- FastAPI
- Uvicorn
